# MasterDegree
Master's degree in Artificial Intelligence Systems (9/2024 - Current)

## List of projects
- First year
    - [search-algorithms](./search_algorithms/): various search algorithms studied in Fundamentals of AI course
    - [online-kmeans](./online-kmeans/): k-means algorithm with CUDA and calibration to perform it in-real-time; project for Signal, Image and Video course
    - [deliveroo-agent](https://github.com/bandomatteo/Deliveroo): an agent which can autonomously play a game of Deliveroo, moving in a map and handling parcels and other agents. Project for Autonomous Software Agents course
    - [nlu-unitn-2025](https://github.com/Nathanoj02/NLU-unitn-2025): use of LSTM and regularization techniques for decreasing perplexity; use of BERT for slot filling and intent classification. Project for Natural Language Understanding course
    - [deep-learning]: in progress. Project for Deep Learning course
    - [gpu-computing]: in progress. Project for GPU Computing course
    - [robotics](https://github.com/Nathanoj02/giraffe-robot): Giraffe robot (RRPRR) model and simulation for Q&A sessions. Project for Introduction to Robotics course

## How to download everything
```
git clone git@github.com:Nathanoj02/MasterDegree.git
```
```
git submodule init
```

If something was updated after the first clone:
```
git submodule update
```
